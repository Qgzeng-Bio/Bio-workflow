# Decision Log

`docs/decisions/Decision_Index.tsv` is the machine-readable authority for decisions that change scientific design, inputs, parameters, result selection, interpretation, figures, or manuscript scope.

Use this Markdown file for longer background when a decision needs narrative context. Keep the stable decision record, evidence path, affected modules/claims, status, and owner in the TSV index; do not maintain a second conflicting copy here.

Decision IDs are stable: `D001`, `D002`, ... Never reuse or renumber an old ID. Supersede a decision with a new ID and reference the old one in Notes.
